夏日课间的邂逅
> 一款网页端校园恋爱视觉小说（Galgame），双男主（BL）设定，纯前端运行，浏览器打开即玩。
---
游戏简介
高二夏天，期末考试前的最后一个午休。你（胖橘）在教室里偶遇一直默默关注的同班同学——王炳程。
从一瓶"买一送一"的可乐开始，两个男生在教室、操场、图书馆之间，慢慢靠近、心动，直到那个黄昏花坛里的告白。
故事包含完整的开端、发展、高潮与结局，情感层层递进，游玩时长约 10 分钟，节奏紧凑不拖沓。

剧情主线（四幕）
第一幕 · 相遇 —— 午休的可乐，日常又默契的互动
第二幕 · 靠近 —— 操场边，王炳程忽然认真：「如果我说想约你呢」→ 选项分支
第三幕 · 心动 —— 图书馆的纸条、黄昏花坛的约会
第四幕 · 结局 —— 最终告白，根据之前的选择走向不同结局
多结局
剧情含 3 种结局，由第二幕的关键选项决定走向：
甜蜜告白线
温柔确认线
普通等待线

操作指南
操作	说明
鼠标点击 / 空格 / 回车	推进对话（打字机效果下可加速显示）
选项按钮	遇到分支时必须点击选择才能继续（不选无法推进）
右上角「自动」	自动播放模式
右上角「跳过」	快进已读内容
右上角「保存 / 读取」	存档与读档
右上角「🔊」	配音开关（静音 / 取消静音）
ESC	呼出菜单
移动端
已做手机横屏适配：竖屏打开会提示「请旋转到横屏」，横屏下立绘、对话框、选项均为优化布局。
选项在横屏下改为双列并排，触控热区 ≥ 44px。

运行方式
方式一：本地服务器（推荐）
在项目根目录执行：
```bash
# Python 3
python -m http.server 8080

# 然后浏览器访问
# http://localhost:8080
```
> 推荐用本地服务器运行，可避免 `file://` 下个别浏览器对音频自动播放的限制。
方式二：直接打开
直接用浏览器打开 `index.html` 即可运行（配音映射以 `<script>` 方式引入，无需额外配置）。

配音说明
配音使用本地 edge-tts（微软神经语音） 生成，按「角色 + 台词」内容哈希命名，台词顺序变动也能复用：
胖橘 → `zh-CN-YunxiNeural`（青春阳光男声）
王炳程 → `zh-CN-YunyangNeural`（沉稳男声）
旁白 → `zh-CN-XiaoxiaoNeural`（温暖女声）
对话开始即播放对应配音，切句自动停止上一句；纯省略号等无可朗读内容的两句为静音跳过（仅显示文字）。
